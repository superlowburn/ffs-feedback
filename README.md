# FFS feedback

**FFS** is a Chrome extension that hides posts about people you're tired of (Donald Trump & his circle by default) and, if you want, ads on X and Reddit.

This repo is where reports and ideas go. The extension's code isn't here.

## Something not hidden? Or hidden by mistake?

Click the FFS icon → **Something not hidden? Send a report**. It opens a new issue here with the page and your FFS settings already filled in. Add a sentence about what you expected and, if you can, a link to the post.

You need a GitHub account to post. Issues here are **public**, so don't paste anything private.

## Ideas

Open an issue and start the title with **Idea:**.

## Privacy

FFS doesn't collect or send anything. It runs entirely in your browser. A report contains only what you see in the issue before you post it.
